# Installation

Le patch BPS version 0.8 s'applique à une copie de Pokémon Cristal Rev. 01 (USA/Europe) obtenue légalement.

1. [Téléchargez le patch](https://github.com/flow71350/pokemon-crystal-legacy-fr/raw/refs/heads/main/patches/pokecrystal0.8.bps).
2. Ouvrez un outil compatible avec le format BPS, comme Floating IPS, et choisissez l'option pour appliquer un patch.
3. Sélectionnez le fichier `.bps`, puis votre ROM de Pokémon Cristal Rev. 01 (USA/Europe).
4. Enregistrez la ROM modifiée et ouvrez-la avec un émulateur compatible.

Aucune ROM n'est fournie dans ce dépôt.
